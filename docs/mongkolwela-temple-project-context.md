## ภาพรวมโปรเจกต์

มงคลเวลาในฝั่งวัดเป็นเว็บไซต์สำหรับคนที่อยากหา “สถานที่ไปไหว้จริง” มากกว่าการอ่านคำทำนาย เว็บไซต์ช่วยให้ผู้ใช้ค้นหาวัดดัง สถานที่ศักดิ์สิทธิ์ สถานที่สายมู และเส้นทางไหว้พระที่เหมาะกับสิ่งที่อยากเสริมในชีวิต เช่น การงาน โชคลาภ ความรัก ครอบครัว สุขภาพ การเริ่มต้นใหม่ หรือการสะเดาะเคราะห์

แกนของเว็บคือการพาคนจาก “ความตั้งใจ” ไปสู่ “สถานที่และแผนเดินทาง” ผู้ใช้ไม่จำเป็นต้องรู้ชื่อวัดตั้งแต่แรกก็ได้ แต่ควรเริ่มจากสิ่งที่อยากขอพร จังหวัดที่สะดวก หรือประเภทสถานที่ที่สนใจ แล้วเว็บช่วยเสนอทางเลือกให้เดินต่อได้

สิ่งสำคัญคือเว็บนี้ไม่ควรให้ความรู้สึกเหมือนเว็บดูดวงเป็นหลัก ฝั่งวัดควรให้ความรู้สึกเป็นคู่มือเดินทางสายมงคลที่อบอุ่น ใช้งานได้จริง และเคารพบรรยากาศของวัด/ศาล/สถานที่ศักดิ์สิทธิ์

## ผู้ใช้หลัก

กลุ่มผู้ใช้หลักมีหลายแบบ แต่มีจุดร่วมคืออยากไปไหว้หรือวางแผนทริปให้เกิดขึ้นจริง

- คนที่อยากไหว้พระ 3, 5 หรือ 9 วัด แต่ไม่รู้จะเรียงเส้นทางอย่างไร
- คนที่อยากขอพรเรื่องหนึ่งโดยเฉพาะ เช่น งาน เงิน ความรัก สุขภาพ หรือแก้ชง
- คนที่กำลังหาวัดดังใกล้จังหวัดหรือภูมิภาคที่ตัวเองจะเดินทางไป
- คนที่อยากเปิดดูข้อมูลวัดทั่วประเทศไทยแบบค้นหาเร็ว
- คนที่อยากเช็กพิกัด รูปภาพ ประเภทสถานที่ และข้อมูลเบื้องต้นก่อนตัดสินใจออกเดินทาง

ความคาดหวังของผู้ใช้:

- เข้าเว็บแล้วรู้ทันทีว่าเว็บช่วยเรื่องวัด สถานที่ศักดิ์สิทธิ์ และเส้นทางมงคล
- ค้นหาได้ด้วยภาษาคนทั่วไป ไม่ต้องรู้ taxonomy ของระบบ
- กดแล้วไปต่อได้จริง ไม่ใช่แค่บทความรวมรายชื่อ
- ข้อมูลต้องดูน่าเชื่อถือพอที่จะใช้วางแผน แต่ยังต้องบอกเมื่อข้อมูลบางอย่างควรตรวจสอบซ้ำ

## เว็บฝั่งวัดมีอะไรบ้าง

### Home

Home เป็นหน้ารวมภาพจำของเว็บ ฝั่งวัดควรเป็น first impression หลักของแบรนด์ มี hero ขนาดใหญ่ ภาพวัด/จิตรกรรม/สถานที่ศักดิ์สิทธิ์ คำว่า “มงคลเวลา” ชัดเจน ช่องค้นหา และทางลัดไปเส้นทางหลัก

หน้าบ้านทำหน้าที่:

- บอก positioning ว่าเว็บนี้คือวัดดัง สถานที่ศักดิ์สิทธิ์ และเส้นทางเสริมมงคล
- ให้ผู้ใช้เริ่มจากความตั้งใจ เช่น โชคลาภ การงาน ความรัก ครอบครัว เริ่มใหม่ แก้ชง
- ดันจุดขาย “วางแผนไหว้พระ” ให้เด่น เพราะเป็นความสามารถเชิง product ไม่ใช่แค่ directory
- เปิดทางไป collection pages และฐานข้อมูลวัดทั่วไทย

### Temple Hub

`/temples/` เป็นหน้าศูนย์กลางของฝั่งวัด ใช้รวม entry points ไปยัง planner, popular temples, sacred places, mu places และ Thailand directory

หน้าที่ของ hub:

- ทำให้ผู้ใช้เห็นภาพรวมว่ามีหลายวิธีเริ่มต้น
- แยกระหว่าง “ไปตามเส้นทาง/ทริป” กับ “ค้นหาสถานที่”
- ช่วยให้คนที่ยังไม่รู้เป้าหมายเลือกหมวดที่เข้ากับตัวเอง

### Planner

`/temples/planner/` เป็น feature สำคัญของเว็บ ผู้ใช้เลือกจำนวนสถานที่ เงื่อนไข พื้นที่ จุดเริ่มต้น เวลา งบประมาณ และสิ่งที่อยากเสริม แล้วให้ระบบช่วยจัดลำดับทริป

Planner มีสอง journey:

- ให้ระบบจัดทริปอัตโนมัติ
- เลือกสถานที่เอง แล้วสร้างแผน

บทบาทดีไซน์ของ planner:

- ต้องดูเป็นเครื่องมือหลักของเว็บ ไม่ใช่ปุ่มรอง
- ต้องลดความกลัวของผู้ใช้ว่า “ไม่รู้จะเลือกอะไร”
- ต้องอธิบายเกณฑ์การจัดทริปอย่างสั้นและมั่นใจ
- ต้องทำให้ผลลัพธ์อ่านง่าย เช่น สรุปทริป timeline ลำดับสถานที่ เวลาโดยประมาณ และลิงก์รายละเอียด

### Popular Temples

`/temples/popular/` รวมวัดและสถานที่ยอดนิยมสำหรับไหว้พระ ทำบุญ และเดินทางเป็น route มงคล

คุณค่าของหน้านี้:

- เหมาะกับผู้ใช้ที่อยากเริ่มจาก “วัดดังที่คนรู้จัก”
- ใช้ ranking/card layout เพื่อให้ scan ง่าย
- มี filter/search และ map action เพื่อแปลงรายชื่อเป็นการเดินทาง

### Mu Places

`/temples/mu/` รวมสถานที่สายมูหรือสถานที่ศักดิ์สิทธิ์ที่ผู้ใช้มักเชื่อมกับการเสริมดวง ขอพร แก้ชง ความรัก การเงิน หรือเทพ/ศาลสำคัญ

ดีไซน์ควรระวัง:

- ไม่ทำให้ดูฉูดฉาดหรือเชิงไสยศาสตร์เกินไป
- ควรคงน้ำเสียง “สถานที่ศักดิ์สิทธิ์และกำลังใจ” มากกว่า sensational
- ใช้ภาษาและสีที่ยังอยู่ในระบบเดียวกับฝั่งวัด

### Sacred Temples

`/temples/sacred/` เป็นหมวดวัดและสถานที่ศักดิ์สิทธิ์ที่เน้นความสำคัญ ความศรัทธา พิกัด และจุดประสงค์การขอพร

คุณค่าของหน้านี้:

- เหมาะกับผู้ใช้ที่เริ่มจากความตั้งใจหรือเรื่องที่อยากเสริม
- ควรให้ความรู้สึกน่าเชื่อถือและสงบกว่า page สายมู
- ควรใช้ภาพ สถานที่ และ metadata ช่วยให้คนเลือกได้เร็ว

### Thailand Temple Directory

`/temples/thailand/` เป็นฐานข้อมูลวัดทั่วประเทศไทย มี filter ตามชื่อวัด ประเภทวัด นิกาย ภาค จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ และสถานะวิสุงคามสีมา

บทบาทของหน้านี้ต่างจาก collection pages:

- เป็นข้อมูลเชิง directory/data-heavy
- ความสวยควรหลบให้ความสามารถในการค้นหาและ scan
- ตารางควรหนาแน่นแต่เป็นระเบียบ
- การ scroll ภายใน table เป็นพฤติกรรมที่ควรถูก preserve

### Temple Detail Pages

หน้ารายละเอียดวัดหรือสถานที่เป็นจุดที่ผู้ใช้ตัดสินใจว่าจะไปจริงหรือไม่

ข้อมูลสำคัญ:

- ชื่อสถานที่ ภาพ และประเภท
- จังหวัด อำเภอ ภูมิภาค
- จุดประสงค์/พรที่เกี่ยวข้อง
- สิ่งที่นิยมสักการะ
- พิกัดและลิงก์เปิด Google Maps
- ข้อมูลเข้าชม เวลาเปิด-ปิด ช่องทางติดต่อ เมื่อมีข้อมูล
- วิธีเดินทางหรือ context การเดินทาง
- ระดับความมั่นใจของข้อมูล
- สถานที่ใกล้เคียงหรือ related cards

หลักดีไซน์ของ detail page:

- ภาพต้องช่วยยืนยันว่าที่นี่คือสถานที่จริง
- Action สำคัญต้องเห็นง่าย: เปิดแผนที่ แชร์ คัดลอกลิงก์
- ถ้าข้อมูลยังไม่ครบ ต้องบอกตรง ๆ แต่ไม่ทำให้หน้าดูน่าเชื่อถือน้อยเกินไป
- Confidence UI สำคัญ เพราะช่วยรักษาความซื่อสัตย์ของข้อมูล

## หลักการดีไซน์เบื้องต้น

### 1. Temple-first, not fortune-first

หน้าฝั่งวัดต้องทำให้ผู้ใช้รู้สึกว่าเว็บนี้ช่วยเรื่องสถานที่และทริปมงคล ไม่ใช่เริ่มจากการทำนายชีวิต ภาษาควรพูดถึงการค้นหาวัด ขอพร ทำบุญ วางแผนเส้นทาง และเตรียมตัวไปไหว้จริง

### 2. Sacred but practical

เว็บควรมีบรรยากาศศักดิ์สิทธิ์ อบอุ่น และมีพิธีนิด ๆ แต่ทุก section ต้องมีประโยชน์ต่อการตัดสินใจหรือการเดินทางจริง ความสวยอย่างเดียวไม่พอ ต้องช่วยให้ผู้ใช้เลือกสถานที่หรือวางแผนได้เร็วขึ้น

### 3. Warm hierarchy

Hierarchy ควรชัดผ่านขนาดตัวอักษร น้ำหนัก ช่องว่าง และภาพ ไม่ใช่ใส่สีเยอะหรือ effect เยอะ หน้าแรกใช้ scale ใหญ่ได้ แต่หน้ารายการ/ตาราง/Planner ต้องคุม density ให้ใช้งานได้

### 4. Trust through honesty

ข้อมูลวัดมีทั้งข้อมูลที่มั่นใจและข้อมูลที่ต้องตรวจสอบซ้ำ ดีไซน์จึงควรมี state ที่พูดตรง ๆ เช่น โปรดตรวจสอบกับสถานที่โดยตรง ความมั่นใจปานกลาง หรือข้อมูลบางส่วนยังไม่ยืนยัน ความซื่อสัตย์แบบนี้เป็นส่วนหนึ่งของ trust

### 5. Journey over article

ฝั่งวัดควรออกแบบเป็น journey: ตั้งใจ → เลือกหมวด/พื้นที่ → เปรียบเทียบสถานที่ → เปิดรายละเอียด → วางแผนหรือเปิดแผนที่ ไม่ควรให้รู้สึกเหมือนอ่านบทความรวมลิสต์แล้วจบ

### 6. Preserve useful density

บางหน้า เช่น Thailand directory หรือ Planner ไม่ควรถูกทำให้โล่งแบบ landing page มากเกินไป เพราะผู้ใช้ต้อง scan เปรียบเทียบ และกรองข้อมูล การจัดวางต้องหนาแน่นพอดีแต่ไม่รก

## ทำไมใช้ theme และสีแบบนี้

### Warm paper background

พื้นหลังโทนอุ่นช่วยให้เว็บไม่แข็งเหมือน dashboard ทั่วไป และเข้ากับบรรยากาศวัด กระดาษ คู่มือเดินทาง และเอกสารเตรียมตัวไปไหว้พระ สีพื้นไม่ควรขาวจัด เพราะจะทำให้ภาพวัด/สีทอง/สีแดงดูแยกจากกัน

### Lacquer red

แดงเป็นสีที่เชื่อมกับความมงคล ความตั้งใจ ความศักดิ์สิทธิ์ และวัฒนธรรมไทย-จีนในบริบทวัด/ศาล ใช้เป็นสีหลักของ CTA และจุดตัดสินใจ เช่น ค้นหา จัดทริป หรือ action สำคัญ

แดงในเว็บควรเป็นแดง lacquer/deep red ไม่ใช่แดงสดจัด เพราะแดงสดจะดู aggressive หรือ promotional เกินไป

### Gold / yellow aura

ทองและเหลืองเป็นสีของแสง เทียน ธูป เจดีย์ พระพุทธรูป และความเป็นมงคล ใช้เป็น border, glow, highlight, shadow หรือ aura เพื่อให้หน้าเว็บมีความศักดิ์สิทธิ์และอบอุ่นขึ้น

ทองควรใช้แบบ restrained ไม่ใช่ metallic effect หนัก ๆ เพราะจะทำให้เว็บดูราคาถูกหรือเหมือนงานพิธีที่ over-designed

### Jade / green

เขียวช่วยบาลานซ์แดงและทอง และเหมาะกับ metadata หรือสถานะที่ต้องการความน่าเชื่อถือ เช่น label, active state, confirmation, confidence หรือข้อมูลสนับสนุน สีนี้ทำให้ palette ไม่กลายเป็นแดง-ทองล้วนจนร้อนเกินไป

### Deep brown / ink

น้ำตาลเข้มและหมึกอุ่นใช้แทนดำ เพื่อให้ตัวหนังสือยังมี contrast ดีแต่ไม่กระด้าง เหมาะกับแบรนด์ที่ต้องการความนิ่งและเคารพบรรยากาศสถานที่

### Temple photography and mural imagery

ภาพจริงเป็นหัวใจสำคัญ เพราะผู้ใช้ต้องประเมินสถานที่ ภาพวัด จิตรกรรม ธูป แสง และสถาปัตยกรรมช่วยให้เว็บดูมีชีวิตและน่าเชื่อถือกว่าการใช้ illustration ทั่วไป

ภาพควร:

- แสดงสถานที่จริงเท่าที่ทำได้
- ไม่มืด/เบลอ/stock จนเกินไป
- ไม่ crop จนดูไม่รู้ว่าเป็นที่ไหน
- มี fallback ที่ดูเข้ากับระบบเมื่อยังไม่มีภาพเฉพาะ

## สิ่งที่ดีไซน์ตอนนี้ทำได้ดี

- Positioning หน้า Home ชัดขึ้นว่าเน้นวัด สถานที่ศักดิ์สิทธิ์ และเส้นทางมงคล
- Planner ถูกยกให้เป็นจุดขายมากขึ้น ไม่ใช่แค่ feature แอบอยู่ในหน้า
- สีแดง-ทอง-เขียวช่วยสร้างโลกของแบรนด์ที่ต่างจากเว็บดูดวงทั่วไป
- Card collections ทำให้ browse วัดจำนวนมากได้ง่ายกว่า plain list
- Detail pages มีข้อมูลประกอบการตัดสินใจค่อนข้างครบ
- Thailand directory รองรับงานข้อมูลหนาแน่นได้จริง
- Confidence/help tooltip เป็น direction ที่ดี เพราะทำให้ระบบดูรับผิดชอบกับคุณภาพข้อมูล

## สิ่งที่ยังขาดหรือทำได้ไม่ดีในมุมดีไซน์

### 1. ภาพสถานที่ยังไม่สม่ำเสมอ

บางวัดมีภาพจริงที่ดี บางวัดใช้ placeholder หรือภาพที่ไม่ได้ช่วยให้ผู้ใช้ประเมินสถานที่มากนัก ทำให้ card grid และ detail pages คุณภาพ visual แกว่ง

ผลกระทบ:

- ความน่าเชื่อถือของบางหน้าอ่อนลง
- Collection pages ดูไม่สม่ำเสมอ
- วัดที่ไม่มีภาพจริงอาจถูกมองว่าสำคัญน้อยกว่า ทั้งที่ข้อมูลอาจดี

ควรปรับ:

- วาง image quality tiers
- ระบุ priority สำหรับวัด top-rank
- ออกแบบ placeholder ให้ดู intentional มากขึ้น และต่างจาก broken/missing image

### 2. Planner ยังอธิบายคุณค่าของผลลัพธ์ได้ไม่เต็มที่

Planner เป็นจุดขายสำคัญ แต่ผู้ใช้อาจยังไม่เข้าใจทันทีว่าระบบจัดทริปจากอะไร และผลลัพธ์ดีพอให้ใช้วางแผนจริงแค่ไหน

ควรปรับ:

- ทำ summary ของ criteria ให้ชัดขึ้นก่อนกดจัดทริป
- หลังจัดทริป ควรสื่อว่า “ทำไมเรียงแบบนี้”
- Result timeline อาจต้องมี visual hierarchy ที่แยกเวลา เดินทาง จุดหมาย และเหตุผลให้ชัดขึ้น

### 3. Map experience ใน design ยังพึ่ง modal/technical state มาก

Map เป็นจุดช่วยตัดสินใจ แต่ตอนนี้ประสบการณ์ visual ของแผนที่ยังรู้สึกเป็น utility มากกว่าจุดขาย ใน production map ใช้งานได้ แต่ใน design review/offline prototype ต้อง fallback ทำให้ความรู้สึกของ feature นี้ยังไม่เต็ม

ควรปรับ:

- มี static map preview หรือ route preview ที่สวยและอ่านง่ายขึ้น
- อธิบาย mapped count/coverage แบบไม่รก
- แยก map action ระดับ collection กับ detail ให้ชัดกว่าเดิม

### 4. Collection pages ยังคล้ายกันมาก

Popular, Mu, Sacred ใช้ pattern ใกล้กัน ซึ่งดีต่อ consistency แต่บางครั้งทำให้บุคลิกของแต่ละหมวดไม่ชัดพอ

ควรปรับ:

- Popular ควรรู้สึกเหมาะกับ route/trip และ ranking
- Sacred ควรรู้สึกสงบ น่าเชื่อถือ และ intent-driven
- Mu ควรรู้สึกเข้าถึงง่ายขึ้น แต่ไม่ฉูดฉาดหรือ sensational
- ใช้ microcopy, section rhythm, tag emphasis และ hero treatment แยกบุคลิกโดยไม่แตก design system

### 5. Home ยังมีหลายทางเลือกที่แข่งขันกัน

Home มี search, hero links, intent cards, route cards, map band, directory cards และ guide links ทั้งหมดมีประโยชน์ แต่ต้องระวังไม่ให้ทุกอย่างดูสำคัญเท่ากัน

ควรปรับ:

- กำหนดลำดับชัดว่า primary path คือค้นหา/วางแผน
- ลดความซ้ำระหว่าง intent cards กับ route cards หากเนื้อหาเริ่มทับกัน
- ทำให้ Planner CTA มี narrative ต่อเนื่องตั้งแต่ hero ถึง route section

### 6. Trust layer ยังไม่ถูกใช้เป็น design system เต็มตัว

Confidence level ใน detail page เป็นจุดเริ่มที่ดี แต่ยังไม่ได้กลายเป็นภาษากลางของเว็บ เช่น card, list, planner หรือ directory ยังไม่ได้สื่อระดับข้อมูลอย่างเป็นระบบ

ควรปรับ:

- กำหนด confidence/status pattern ที่ใช้ซ้ำได้
- แสดงเฉพาะจุดที่มีประโยชน์ ไม่ใส่ทุก card จนรก
- ทำให้คำว่า “ควรตรวจสอบก่อนเดินทาง” เป็น helpful microcopy ไม่ใช่ disclaimer ที่ทำให้ผู้ใช้กังวล

### 7. Mobile density ต้องตรวจต่อเนื่อง

ฝั่งวัดมีข้อมูลเยอะ โดยเฉพาะ Planner และ Thailand directory การ responsive ต้องรักษาทั้ง readability และ task completion ไม่ใช่แค่ไม่ overflow

ควรปรับ:

- ตรวจ tap targets ใน filter chips และ planner controls
- ลดความยาว label/ปุ่มในจอเล็ก
- ทำ sticky/context controls เฉพาะจุดที่ช่วยจริง
- คุม tooltip/dialog ไม่ให้ชนขอบจอหรือถูก container clipping

### 8. ภาษาบางส่วนยังเป็น generic

บาง card copy ยังใช้โครงซ้ำ เช่น “เลือกสถานที่และเส้นทางที่เกี่ยวข้อง” ซึ่งใช้งานได้ แต่ยังไม่ช่วยให้แต่ละ intent มีรสและเหตุผลต่างกัน

ควรปรับ:

- เขียน copy ให้สะท้อนสถานการณ์จริงมากขึ้น
- โชคลาภ การงาน ความรัก ครอบครัว เริ่มใหม่ แก้ชง ควรมี nuance ของตัวเอง
- หลีกเลี่ยงคำที่ฟังดู horoscope-first หรือ vague เกินไป

## Design Priorities ถ้าจะปรับรอบถัดไป

1. ทำ Planner result ให้เข้าใจง่ายและน่าใช้ขึ้น เพราะเป็น product differentiator
2. ยกระดับ image system สำหรับวัด top-rank และ fallback states
3. แยกบุคลิก Popular / Sacred / Mu ให้ชัดขึ้นแบบไม่หลุด palette
4. ทำ trust/confidence pattern ให้ใช้เป็นระบบมากขึ้น
5. ปรับ Home hierarchy ให้พาผู้ใช้ไป search หรือ planner ได้ตรงกว่าเดิม
6. ตรวจ mobile Planner และ tooltip/dialog ด้วยจอจริงหลายขนาด

## สิ่งที่ควรระวัง

- อย่าทำให้เว็บกลายเป็น landing page สวยแต่เดินทางต่อยาก
- อย่าเพิ่ม effect สีทอง/ออร่าจนอ่านยากหรือดู cheap
- อย่าทำให้สายมูดู sensational เกินไป
- อย่ามาตรฐานทุก collection จนสูญเสียบุคลิกของแต่ละหมวด
- อย่าลด density ของ directory/table จนค้นหาข้อมูลจริงช้าลง
- อย่าใช้ภาพ atmospheric ที่ไม่บอกสถานที่จริงมากเกินไป

## One-line Design North Star

มงคลเวลาฝั่งวัดควรเป็น “คู่มือเดินทางสายมงคลที่อบอุ่น น่าเชื่อถือ และพาผู้ใช้จากความตั้งใจไปสู่สถานที่จริงได้เร็วที่สุด”
